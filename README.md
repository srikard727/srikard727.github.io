# Personal website

Install dependencies with `npm install`, then run `npm run dev`.
Run `npm run build` to create the deployable static site in `dist/`.

Only the Projects section uses React. It mounts the supplied
`RadialOrbitalTimeline` component from `src/components/ui/radial-orbital-timeline.tsx`.
Edit the project data in `src/projects.tsx`. Existing page behavior remains in `script.js`.
